In this project I am aiming to build upon and apply new and innovative explaianble Reinforcement learning techniques. 

As a baseline I am first applying them to gridworld as a sandbox environment to get a better understanding of the new methods. My goal is to then apply the XRL methods to a more complex environment like self driving cars using the Metadrive simulated environment. 


### Overview of XRL methods 
The explainable reinforcement learning (XRL) methods implemented in this repository are adapted from the Counterfactual Shapley Values (CSV) framework introduced by Shi and Liu (2026) [1].
